# Monthly Showcase Video

The homepage video section reads from this exact file:

    assets/video/monthly-showcase.mp4

## To update it each month

1. Export or record your new video (phone footage works fine).
2. Keep it under ~15 seconds and under ~15MB if possible, so it loads fast on mobile data.
3. Convert it to .mp4 (H.264) if it isn't already — most phone cameras already save in this format.
4. Rename your new file to exactly:  monthly-showcase.mp4
5. Replace the file at assets/video/monthly-showcase.mp4 with your new one, keeping the same filename.
6. Re-upload the whole site (or just this one file, if your host allows single-file updates).

No code or HTML changes are needed — the page always plays whatever file has this name.

## Tips for good footage
- Film in good natural light, landscape orientation if possible (the section is wide, not tall)
- A few seconds each of: the engraving process, a finished piece catching the light, and packaging being wrapped works well
- The video autoplays muted and loops, so it doesn't need audio or a clean start/end — a smooth few-second loop is enough
